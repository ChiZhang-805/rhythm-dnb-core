# 研究方案

目标是预警未来 7 天内首次出现的、至少提前 24 小时可识别的行为节律失稳。这是待验证的研究终点；不能直接等同于临床昼夜节律疾病。

## 固定流程

真实观测 → 每日指标 → 稳定参考与固定尺度 → 群体模块发现 → 个体分数 → 报警校准 → 独立人群测试。

主面板 `joint12` 包含睡眠中点、睡眠时长、首次/末次热量摄入时间、最活跃 10 小时的起点、活动相对振幅、活动总量、静息心率，以及文本中的焦虑、悲伤、醒后疲劳、压力。客观对照面板 `objective8` 只用前八项；两种面板各自发现和校准，不根据测试成绩挑选。

| 环节 | 具体做法 |
| --- | --- |
| 量化 | 钟点按圆周处理，跨午夜不会被误认为相差 23 小时；时长按实际时间计算；缺失不填零。 |
| 群体发现 | 在独立开发人群中比较稳定与事件前状态；按人重采样，置换时使用候选最大统计量控制搜索带来的偏差。 |
| 经典 DNB | 组内标准差均值 × 组内相关绝对值均值 ÷ 组外相关绝对值均值；同步上升和反向波动都能计入。 |
| 个体 sDNB | 将个人当日向量加入固定稳定参考，计算相关扰动；主分析遵循原论文的组内 K² 均值约定。 |
| 滚动对照 | 用本人过去 28 天的共同完整观测计算经典 DNB，至少 23 天合格。 |
| 报警 | 在校准人群中选择阈值，连同连续超阈、冷却期和多个模块取最大值的整套策略一起评价。 |

正负交替等模式必须在足够的实际观测中体现为可估计的相关变化；当前主算法不自动搜索任意时滞或所有序列形状。外部相关接近零、方差不足或数据不合格时拒判，不用小常数制造高分。

## 真值与验证

结局只根据睡眠、饮食、活动的客观节律变化定义。稳定人群拟合各域异常界限，个人基线用于比较；至少两个域异常并连续持续 3 天才确认事件。事件起始和确认时间分别保存。文本分数、DNB 分数不参与定义真值。

参考、发现、校准、测试按人隔离；文本训练也按人和同源文本组隔离。每次回放只能读取当时已经产生且已经到达的数据。测试必须同时提供独立事件登记和监测日历，漏报的预测日也进入覆盖率分母；未来随访不完整不能当成阴性。

报告事件检出率、提前量、每 30 天误报数、可评分覆盖率，以及按人重采样的区间。线性、样条和树模型在开发数据中选参数，作为对照。阈值校准失败或没有稳定群组属于有效结果，不能降低门槛凑出模型。

默认参数均为可检验的起点，见 [参数表](parameters.csv)。先登记选择，再开发和校准，最后只评一次锁定测试集。修改测量或终点规则后，从原始来源重建对应产物并重新校准。

人数下限按精度重新设定：稳定参考 100 人时，近零相关的 [Fisher 近似](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.pearsonr.html)95% 区间半宽约 0.196；端点参考至少 200 人，使 95% 分位数约有 10 个人份的尾部支持；报警校准至少 100 位发生事件者，独立二项近似最坏区间半宽约 0.098。同人重复事件不增加这一人数。以上是研究设计起点，分层、相关性和选择偏差都可能要求更多数据；30 个阴性日仅是运行保护，不能称为验证充分。

模块 bootstrap 改为 10000 次，最坏 Monte Carlo 标准误不超过 0.005；置换改为 9999 次，p 值分辨率为 0.0001。14/28 天窗口、持续 3 天、误报预算和文本优化参数仍须真实队列验证。DNB 原论文没有为行为节律规定这些数值。

## 计算依据

文本主模型固定为 **Qwen3-8B**，仅保留 **MacBERT-base** 作可选对照；这是依据公开研究与可部署性作出的选择，尚非本项目实测冠军。

| 候选 | 比较结果 |
| --- | --- |
| Qwen3-8B | 纯文本架构、开放权重、可做 LoRA；2026 年情绪强度回归预印本直接使用该底座，支持其作为主候选。 |
| MacBERT-base/large | 中文编码器成熟、训练成本低；通用中文任务成绩不能证明程度评分最佳。保留 base 衡量复杂模型的增益。 |
| ChineseModernBERT / Qwen3.5 | 更新的通用中文编码或模型能力值得关注，但尚未找到足够直接证据证明对本研究的情绪强度和纵向波动更优，暂不增加主线。 |

[SemEval 2025 官方结果](https://aclanthology.org/2025.semeval-1.327/)的中文强度任务中，组织者 RoBERTa 基线 Pearson 为 0.405，TeleAI 为 0.708，PAI 为 0.722。后两者使用大模型微调/集成，不能把成绩算到单个 8B 模型上；RoBERTa 也不等于 MacBERT。[Qwen3-8B 直接研究](https://arxiv.org/abs/2608.06425)使用英文数据、额外推理监督与强化学习，属于预印本；本项目的直接回归头不是该方法的复现。

先用真实中文标注微调并单独校准“文本是否有依据”，同时检查 MAE、相关、一致性、预测/人工标准差比和同人变化。DNB 依赖波动与相关，不能只追求低误差；共同评分误差也可能制造假相关。公开 [BRIGHTER 数据](https://aclanthology.org/2025.acl-long.436/)可作外部对照，但没有覆盖本项目全部 17 项，不足以直接训练完整量化器。[MacBERT 论文](https://aclanthology.org/2020.findings-emnlp.58/)和 [Qwen 模型卡](https://huggingface.co/Qwen/Qwen3-8B)用于核对模型定义。

- [Chen 等，2012，DNB 原始论文](https://doi.org/10.1038/srep00342)：临界转变前的波动与相关性信号。
- [Liu 等，2017，单样本 DNB](https://doi.org/10.1371/journal.pcbi.1005633)：固定参考与个体网络扰动。

论文支持算法定义；迁移到行为节律预警的效果仍须通过真实纵向数据验证。

## 修缮结果与验证边界

2026-10-06 已完成六次 A40 训练：同一份 1,584 条训练、112 条验证语料，比较有/无范围监督，各跑三个预登记种子、最多两轮。没有新增猜测的数值标签；补充的文字只教“有没有依据”。局部验证只有 9 项有程度参考，不是 17 项全部验收。

验证 MAE：对照 **3.63 ± 0.11**，范围监督 **3.82 ± 0.21**（均值 ± 种子标准差，不是总体置信区间）。以下再检查原主模型与六个候选；自建参考和既往看过的场景均只作开发回归，不能称为新封存测试：

| 模型 | 普通文字 MAE | 同义语境偏移 | 连续变化 MAE |
| --- | ---: | ---: | ---: |
| 保留原主模型 | 4.97 | 21.22 | 5.81 |
| 对照候选，三次均值 | 5.08 | 15.03 | 5.97 |
| 范围监督候选，三次均值 | 5.07 | 16.36 | 5.96 |

普通文字为更新来源后的 3,390 条，原先 4.91 分对应旧 3,420 条参考，两者不可直接比较。候选减轻部分语境干扰，但普通文字、连续变化和依据判断没有同时改善，因此**保留 `rhythm-text-expanded`，不自动替换**。范围监督系数 0.01 是被实际比较过的候选，不是已确定的最优值。

| 七项问题 | 已落实 | 尚缺的证据 |
| --- | --- | --- |
| 参考分可靠性 | 生成 403 段文字的双人盲审包、17 项端点说明和分歧检查；不自动平均或改库 | 两位独立标注者实际完成复核与仲裁 |
| 人物、时间与引用 | 证据/排除片段进入训练损失；辅助头读取完整上下文；完成匹配预算复验 | 更丰富的独立场景；本次没有全面胜出的新模型 |
| 17 项覆盖 | 每项单独计数、误差、范围；主配置拒绝缺少任一训练或验证指标 | 稀缺指标的充分程度标签、全范围独立检验 |
| 无依据时拒判 | 六种标签状态；未标注不当负例，未校准实验值放在 `estimates`，下游 `scores=null` | 有代表性的独立证据校准；小实验不足以确定接收门槛 |
| 个人波动 | 从只读源库刷新 2,445 段文字，保留划分；最终 38,667 条带来源时间；检查变化、间隔、个体相关结构 | 这些是自编文本对齐的源时间，不能代替真实提交时间和纵向效度 |
| 节律规则与窗口 | 睡眠质量与客观规律性分开；登记 21/28/35 天预测窗口比较，固定结局与预测期限 | 足够完整的客观连续记录；窗口尚无实测最优值 |
| DNB 增益 | 比较器强制同人、同预测时点、同结局与监测日历、同误报预算；仅校准组定门槛 | 独立事件登记与随访，才能真正比较简单趋势、客观面板、文本联合面板和 DNB |

恢复来源时间后的个体相关误差检查已运行，但共享编写习惯和参考误差仍可能影响网络；不能将自建数据中的相关关系当作生理网络。新封存工具只验证相对于给定暴露清单的隔离，还需要人工检查语义近重复。

完整运行、逐指标表、来源哈希和图在本地 `runs/research-repair/`；其中 `analysis.json` 是本轮结果，`blind-review/` 是尚未完成的复核包。各入口见 [训练说明](training.md)。

### 文献怎样影响选择

- **继续用句子/上下文评分。** [SemEval 2018](https://aclanthology.org/S18-1001/)区分情绪强度与总体情感方向；[PAI 2025](https://aclanthology.org/2025.semeval-1.150/)使用上下文表征、微调和集成。现有 Qwen 的末位表示可以接收前文，不等于仅看最后一个词；本轮已加入人物与时间范围的辅助监督，但尚未证明全面增益；不能认定增加一个头、改均值池化或换更大模型必然更好。
- **先提高标注可信度。** [BWS 研究](https://aclanthology.org/P17-2074/)支持用相对强弱比较改善情感标注一致性；可结合明确量表锚点，不能把比较排名自动当成临床刻度。[CheckList](https://aclanthology.org/2020.acl-main.442/)和[对照样本](https://aclanthology.org/2020.findings-emnlp.117/)支持分别检验含义不变时稳定、含义改变时响应正确。
- **公开语料只能补相符的任务。** [BRIGHTER](https://aclanthology.org/2025.acl-long.436/)可作中文情绪外部对照，其 0–3 强度标签不证明 0–100 精细刻度；恐惧也不能直接改名为焦虑。[CDVAI](https://aclanthology.org/2022.rocling-1.19/)适合研究中文句子/上下文与反话，但不能补齐睡眠、饮食的全部标签。[Dreaddit](https://aclanthology.org/D19-6213/)研究英文压力识别，也不是本项目中文连续压力分数的现成真值。
- **保留 Qwen 主线，但“最佳”尚未证明。** [2024 年多任务比较](https://aclanthology.org/2024.findings-naacl.246/)表明大模型在复杂情感任务上仍有局限；保留 MacBERT 同数据对照。[2026 年 Qwen3-8B 预印本](https://arxiv.org/abs/2608.06425)研究英文数据的全参数 SFT+GRPO，不等于已验证我们的中文 LoRA 回归头。当前不优先引入强化学习。
- **节律不是一个主观睡眠分数。** [2021 年指标研究](https://doi.org/10.1093/sleep/zsab103)区分跨天总体差异、逐日变化及睡眠碎片化，并指出短记录的偏差。[2026 年 SLEEP 观点文章](https://doi.org/10.1093/sleep/zsag114)仍强调轮班、光照、进餐等共同影响和前瞻性验证；它不是本项目阈值的实验证明。现有 7 天事件窗口应作敏感性分析，不能据论文直接改成某个“最佳天数”。
- **迁移 DNB 是待检验假设。** 经典 DNB 的 SD/PCC 组合不辨识任意时滞；同时重排同一窗口内所有观测行不会改变该组合。[sDNB](https://doi.org/10.1371/journal.pcbi.1005633)依赖固定稳定参考，单次偏离不等于个人已经接近临界点。[活动记录研究](https://www.nature.com/articles/s41398-021-01465-w)提供初步支持，但要求进一步评价误报；[2024 年日记研究](https://doi.org/10.1017/S0033291723003811)和[2025 年前瞻性情绪研究](https://doi.org/10.1177/21677026241305136)提示信号的稳定性与敏感度仍有限。这些是相关方向的证据，不是对本项目 DNB 的直接验证或否定。

下一轮先完成盲审、补足稀缺程度标签与独立证据样本，再建立新的封存测试。新方法须同时检查语境能力、普通文字和连续变化；验收界限来自标注一致性与使用需求，不能凭平均误差临时挑数。最后才检验文本对 DNB 预警的实际增益。

上一轮诊断仍保留在 `runs/research-assessment/`；研究数据与模型不进入公开源码仓库。

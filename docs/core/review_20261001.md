# DNB 迁移与全仓复核：2026-10-01，核心版本 0.2

结论：本项目可以作为“行为节律失稳的提前预警”研究开展；目前不能把慢性病应用中的成功直接迁移成已经有效的节律预警器，也不能声称现有参数已经最优。本轮不仅审查方案，也修改了实际计算、输入资格、结局和评估代码。最终交付物、逐文件台账与图表见本文末尾。

## 1. 研究问题的边界

用户的目标是：原始文本经过监督学习得到连续语义程度，事件时间和传感器记录经过可复核规则得到数值，再研究多变量网络是否出现临界转变前的协同变化，最终对一个人在未来时间窗是否需要预警给出 0/1。数据不足、未完成校准或没有可靠模块时必须保留未知状态，不能把未知包装成 0。

需要修改一个理解：DNB 本身不是任意复杂神经网络，也不自动学习所有排列模式。经典 DNB 对同一状态的一组样本检验三种变化：组内 SD 上升、组内绝对 PCC 上升、组外绝对 PCC 下降。正、负相关都计入，但零时滞 Pearson 相关不能发现所有非线性或滞后关系。仅一起升降还不够；群体分布、样本数、共同测量误差也会改变这些分量。[Chen 等，2012](https://www.nature.com/articles/srep00342)

sDNB 将一个完整个体样本加入固定稳定参考，计算绝对偏差与相关扰动。代码保留论文 K² 组内平均的约定；它与无序对均值相差 `(K−1)/K`，不同约定不能共用阈值。我们采取“群体开发集发现、冻结模块、独立个体评分”的组合方案；这包含项目自己的选择，不能称为原论文全部步骤的逐项复刻。[Liu 等，2017](https://journals.plos.org/ploscompbiol/article?id=10.1371/journal.pcbi.1005633)

“行为节律失稳”也不是已经证明的内源性昼夜节律紊乱。短睡、晚睡、相位变化、不规则、睡眠碎片化分别测量不同方面。S1 的离散程度和 A1 的 IS 对部分日序重排不敏感；即使每天顺序变了，它们也可能相同。SRI/相邻日变化可作为事先规定的敏感性分析，不能事后挑选最好看的指标替换结局。[Fischer 等，2021](https://doi.org/10.1093/sleep/zsab103)

## 2. 当前确定的流程

1. 固定采集协议、量化版本和目标人群。默认为成人、非轮班的行为节律研究；夜班、跨时区旅行、急性病、药物调整与设备更换须分层或作为明确的排除/敏感性因素。
2. 逐事件保留开始、结束、真实可得时间、时区、单位、缺失原因和来源证据。原始数据与派生值分离。
3. 文本模型独立训练和验证。按人、原始记录及模板组隔离，经过复核的程度标签不能由拟预测的结局反推；同一冻结模型生成全部网络文本节点。
4. 得到 objective8 与 joint12 两个预定义面板。完整参考人、群体开发人、校准人、最终测试人分开。时间截止也有序。
5. 参考只决定环形中心、均值和 SD；不在每个目标窗口重新标准化。群体发现同时要求三个 DNB 方向、按人 bootstrap 稳定性以及候选集合最大统计量置换检验。
6. sDNB 是主要个体评分路径；个人滚动经典 DNB 是必须独立校准的比较路径。记录三个分量与有符号相关，不能只留下最大分数。
7. 独立结局分支生成 S1/E1/A1、个人基线、阈值、连续事件及标签。真实开发样本要求来源合格的成对面板与事件时间，真实校准和测试要求相同 `outcome_protocol_id`、事件登记与监测日历。
8. 校准完整报警策略，再冻结 bundle；测试阶段不再选模块、阈值或参数。统计事件灵敏度、误报/风险人时、提前量、PPV、数据覆盖率与按人重采样区间。

当前 objective8 还缺少同一人、同一天的完整观测；joint12 额外受文本模型外部效度限制。两者是预定义方案与对照，不得看完测试结果后选择较优者并只报告它。

## 3. 每类数据如何量化

| 输入 | 量化规则 | 不能做的替代 |
| --- | --- | --- |
| 实际睡着区间 | UTC 经过时间；v2 日总时长仅累加研究日内部分，主睡眠中点按主睡眠完成日归属 | 将卧床当睡着；将凌晨前片段重复计入第二天；把 wake=0 当 asleep |
| 主睡眠中点 | 明确主睡眠开始到最终醒来区间中点，再转本地钟点 | 多片段时自动选最长一段当整晚 |
| 含能量进食 | 完整记录中按实际时间顺序取首末含能量事件，再提取钟点 | 直接对 23 点和 1 点求算术平均；缺少热量证据便默认吃过或没吃 |
| 活动计数 | 合格小时按计数/实戴分钟×60；完整 24 格算 M10、L5、RA 与总量 | 将没戴设备记为零；将设备步数、加速度 counts 混作同单位 |
| 活动相位 | 唯一 M10 最大起点；并列最大时相位未知，RA/总量仍可保留 | `argmax` 静默挑第一个小时，制造虚假的相位变化 |
| 静息心率 | 设备已定义的 resting HR，或有明确静息掩码的样本中位数 | 一天心率最小值直接当静息心率 |
| 文本程度 | 固定 MacBERT、多类别有界回归头、连续 0–100；模型身份写入特征 | 把 0–100 当发生概率；改写后的文本自动升格为真实自述 |
| S1/E1 | 7 日钟点的环形 SD；E1 取首餐和末餐两种离散度较大者 | E1 的 max 是已登记的敏感端点定义，不是理论证明最优；不能和其他定义混用阈值 |
| A1 | 同一处理协议下小时格的 `1−IS` | 没有小时数据时用日总步数伪造 A1 |
| SRI/IV | 分别需要明确连续时间格及睡眠状态/活动序列 | 用日中点或日总量恢复不存在的状态序列 |

日界线 04:00、次日正午发报是可执行的研究安排，不是最佳生理时刻。它会推迟纳入凌晨 04:00 后才完成的睡眠；当前采取严格已完成记录原则。正式采集前应比较 04:00 与其他日界线/发报时刻造成的延迟和覆盖，换方案必须产生新的量化版本与阈值。DST 的 23/25 小时活动日目前拒绝自动补成 24 格；这是保守缺失策略，必须报告其覆盖损失。

参考均值用于偏差、SD 和 PCC 的数学定义，不是随意用“平均”替代建模。个人端点基线取中位数是抑制少数极端基线日影响的研究选择；本文没有宣称它优于所有稳健方法。文本 MAE 的常数比较器现在同时报告训练中位数，MSE/RMSE 的常数比较器保留训练均值。

## 4. 参数登记与调整建议

完整清单在 [parameters_v2.csv](parameters_v2.csv)，包含 StudyConfig 的每个字段、文本训练设置和函数级参数。以下是对科学结果影响最大的选择。

| 参数 | v2 默认 | 依据与下一步 |
| --- | --- | --- |
| 个人基线/随访 | 14 日 / 建议 84 日 | 覆盖多个工作日与休息日；非经验最优。比较 14/21/28 日基线；84 日属于采集设计，目前不是代码强制条件 |
| 结局窗口、有效日、持续性 | 7 / 6 / 3 | 周期可解释且保留有限缺失；连续重叠窗口不是独立证据。敏感性 7/14、6/7、2/3/4；改动意味着换结局定义 |
| 结局稳定分布分位数 | .95 | 稳定人群的经验参考界限，不是临床诊断线；按人等权拟合真实数值。候选 .90/.95/.975 应先登记，不能以提高 DNB AUC 反向选择 |
| 参考人 / 结局阈值参考人 | 各至少 60 | 工程研究起点，非 sDNB 论文证明的最优人数。9 是当前 sDNB 最低计算门槛；60 仍可能远不足以估计分层尾部，需按精度与学习曲线设计 |
| 个人滚动窗口 | 28 日、23 个完整日、缺失连续≤2 日 | 降低小样本相关不稳定；有延迟/非平稳权衡。比较 14/28/42/56 日，整套重新校准；当天缺失必须停止评分 |
| 模块大小/数量 | 2–4 / 最多5 | 低维可穷举、可解释；objective8 有154组，joint12有781组。并非所有行为依赖只能是此大小；更多组合须纳入同一搜索校正 |
| bootstrap / 稳定性 | 1000 / .70 | 1000 次在真实稳定性 .70 附近的 Monte Carlo SE 约 .0145；它只是计算误差，不能代替队列不确定性。.70 是待验证门槛，比较 .70/.80/.90 |
| 置换次数 / 显著性 | 999 / .05 | 分辨率 .001；采用 `(1+b)/(1+B)`，避免零 p 值。临界结果可预先规定增加到9999，不应重抽直到显著 |
| 报警持续 / 冷却 | 2 日 / 7 日 | 控制单日噪声和重复报警的产品研究选择；比较1/2/3日与3/7/14日，评价完整策略 |
| 预测时间窗 / 最小提前量 | 7 日 / 24 小时 | 与可干预时间相关的项目目标；不是由现有数据证明最优。可比3/7/14日，但每种标签与阴性随访均需重建 |
| 误报预算 | 每30有效风险日≤1次 | 人机使用负担的研究目标，不是概率阈值1.0；阈值从独立校准组分数搜索得到。另报告覆盖率，防止大量拒判“优化”误报 |
| 校准最低资料 | 10事件、30阴性日 | 仅阻止极少资料下运行；绝不是充分样本量要求。10事件灵敏度误差很大，30日零误报也不能证明未来≤1次/月 |
| `epsilon` | 1e−8 | 浮点/近零分母拒判保护，不是模型概率阈值；比较1e−10/1e−8/1e−6时报告拒判率，不能通过分母加epsilon制造大分数 |
| 每小时/每日佩戴 | 45分钟 / 1200分钟 | 保守项目规则，且仍要求完整24格。较短小时阈值会放大暴露外推；敏感性须连同测量版本和重新拟合执行 |

置换扩展假设在全局无条件差异的零假设下，每个人的两种条件可交换，并用每轮所有候选的最大统计量控制全局零假设下的搜索误报。时间趋势、非交换的阶段变化与部分备择下的强控制不由此自动解决。它不是因果证明，也不把 .70 稳定率当作 p 值。[Phipson 与 Smyth，2010](https://pubmed.ncbi.nlm.nih.gov/21044043/)

调参应使用开发集内按人隔离、保留时间方向的内层比较；独立校准组确定完整报警策略，最终测试集只用于一次锁定评估。要同时报告失败配置和全部主要候选。逻辑回归、二/三阶样条及提升树是已实现的对照，模型复杂度不能代替数据与标签资格。

## 5. 实际修复及为什么需要版本升级

| 风险 | 已落实的处理 |
| --- | --- |
| 跨日主睡眠补回片段导致总时长重复；wake误算睡眠 | 按研究日裁剪时长；只接受显式 asleep=1；微秒未对齐小时也拒绝 |
| 窗口够长但当天缺失仍输出滚动分数 | 当天完整性独立门控；未结束研究日也不可入参考 |
| 离线日期与线上本地日不一致；状态跨方法复用 | 离线复用 forecast_bounds；状态绑定方法、时区及bundle |
| 未来确认提前可用；重复域伪造多域异常 | 每个评估日须真实完成；域唯一且合法；确认、提前量、随访与事件登记交叉检查 |
| 配置没有穿透结局计算 | 新增 endpoints 工作流与CLI；基线、窗口、有效日、持续性、分位数和标签时间窗贯通 |
| 只接收无来源的开发向量，或混用结局 | 真实开发需要双面板、来源资格与事件时间；各阶段冻结同一protocol id |
| 候选枚举多重搜索造成偶然群组 | 向量化三个分量、按人bootstrap与最大统计量置换控制；允许无模块结论 |
| 删除缺失预测日造成虚高覆盖 | 真实研究强制独立监测日历；缺失日仍在覆盖率分母中且不是阴性 |
| 真实/模拟混合谱系被标成纯模拟 | 混合来源为unknown，两种主分析资格均拒绝 |
| bundle尺度可自洽但不来自所述参考 | 重算参考尺度和环形中心核验；拒绝重复模块与旧schema |
| CSV重复列静默覆盖、布尔/无穷值混进数字 | 在导入和配置边界拒绝；核心SQLite校验schema，追加面板/预测审计 |
| M10并列最大被任意取第一个；文本仅有均值比较器 | 相位未知；增加训练中位数MAE基线 |
| 溯源统计混入metadata，或忽略不同来源格式 | 只计数值字段，识别文件/字段、工作表/行、共享源清单和来源计算；改写优先判为constructed |

量化语义已经变化：FeatureValue.version=2、bundle.schema_version=2、核心SQLite schema=2、SEA-v2。旧产物不会被自动改写；需要从原始证据重建面板、结局并重新校准，不能只修改版本号复用旧阈值。独立仓库仅发布 v2 配置，新研究入口使用 study_v2.json 或 study_objective8_v2.json。

## 6. 已经确定不能忽视的问题

- 共同文本模型误差能制造组内相关与波动；设备固件变化、上传批次或问卷提示变化也可能产生同样结构。机制对照已保留共享误差情景。
- sDNB 同一天同一向量的分数不会因历史不同而改变。因此稳定个人特征与刚出现的偏离可能同分；晚型人群/个体基线分层和纵向对照需要真实数据验证，不能用一个高分宣称“即将”。
- 小样本相关、强周期、均值趋势、噪声结构和突发外部冲击都可能破坏临界转变解释。当前程序不默认去趋势，以免也消除真实前兆；因果、仅使用过去数据的残差分析须另行预注册。[Jäger 与 Füllsack，2019](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0211072)
- 文本0–100是否具有可比较的间距、不同人描述风格是否可比、评分误差是否相关，尚无合格独立人体数据证明。神经网络能输出小数不代表测量学已经成立。
- SEA 与部分预测变量使用同源观测，存在标签构造耦合。需要独立功能变化/临床评价；真正研究内源性节律还需适当相位测量。全夜未睡导致中点未知，当前规则可能拒判，应报告并另设计经过验证的事件子型。
- 现有来源不能按列横向拼成一个虚拟人。LifeSnaps 的多模态设计有参考价值，但不等于当前本地导入表具备全部同步数据；PMData 的食物图片也不自动等于完整首末餐日志。[LifeSnaps 原始论文](https://doi.org/10.1038/s41597-022-01764-x)、[PMData 原始论文](https://web-backend.simula.no/sites/default/files/publications/files/3339825.3394926.pdf)

## 7. 结构、覆盖范围与复现

保持研究核心与 NAVA APP 分离，沿用 contracts → measures / dnb → warning，以及离线 outcomes / research → workflows 的分层。参考了 [pyActigraphy](https://github.com/ghammad/pyActigraphy) 的输入/指标/分析拆分和 [GGIR](https://github.com/wadpac/GGIR) 的分阶段处理。新加 endpoints.py 是跨步骤编排，lineage.py 专门解释历史来源格式，plots.py 只画图，review_research.py 只扫描并保存证据，均有实际实现。独立发布保留这些分层；数据库不随源码发布。

最初全仓复核包含旧兼容代码与数据修缮入口；本仓库仅发布科研核心。公开诊断脚本扫描本仓库的 Python/JSON 文件，记录哈希、导入、数值常量、函数和注释，结合行为回归检验。它不等同于逐行形式化证明，也不代表重新逐字审核人工文本。迁移前结果通过合成回归夹具保留，无需旧工程即可运行。

```powershell
python -m unittest discover -s tests -q
python tools/review_research.py --output-dir runs/new-review
python -m rhythm_dnb --help
```

独立仓库测试与构建结果记录在 [verification_v2.md](verification_v2.md)。诊断默认生成有符号相关热力图、DNB 三个分量柱状图、负相关散点图及参数敏感性箱线图；只有显式提供本地数据库才生成各数值字段分布与来源覆盖图。合成控制全部明确标注，不作为真实准确率。
